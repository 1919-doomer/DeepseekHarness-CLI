# Decision map

Accepted ADRs:

- ADR 0001 — official out-of-process SDK runtime boundary;
- ADR 0002 — renderer separated from upstream event semantics;
- ADR 0003 — `dshc` working binary name;
- ADR 0004 — GitHub as project source of truth.

Future architecture reversals should supersede, not silently contradict, these ADRs.
