# Naming

## Project name

Public descriptive name: **DeepSeek Harness CLI**.

The repository currently uses `DeepseekHarness-CLI` as its GitHub name.

## Executable

Working executable name: **`dshc`** — DeepSeek Harness Console.

Reason: upstream already owns `dsh`; this community project must not shadow the official command.

## Package name

The final package/distribution name is intentionally not fixed during M0. Before M5, check registry availability, trademark/confusion risk, and installation ergonomics.

The package name does not have to equal the executable name.

## Affiliation language

Always describe this repository as an independent/unofficial community project interoperating with DeepSeek Harness. Do not imply endorsement or maintenance by DeepSeek AI.
